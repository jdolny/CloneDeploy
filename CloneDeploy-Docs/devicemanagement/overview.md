# Device Overview

CloneDeploy manages computers through an installed agent. The agent enrolls with the server, collects inventory and runs assigned policies and actions. Administrators use the web interface to review devices, deploy software and configuration changes, and provide support.

Configure the server before beginning. Start with one or two test computers and work through these steps in order:

1. **Prepare for Device Management** — choose agent features, configure access and branding, set enrollment rules and generate the enrollment key, then prepare and download the agent release.
2. **Install the Agent** — install on a test computer, approve enrollment when required, and verify connectivity.
3. **Create Your First Policy** — collect inventory from the test devices and confirm the results before expanding deployment.
