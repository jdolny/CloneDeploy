# Imaging Overview

Prepare a reference computer, capture an image, and deploy it to a test computer using WinPE.

Complete installation and initial setup, including storage, before preparing imaging. Use a destination test computer whose existing data can be replaced.

1. Complete Prepare for Imaging to install the WinPE prerequisites, build a boot environment and configure network boot if needed.
2. Follow Prepare an Image for Capture to build and customize the reference computer.
3. Follow Your First Capture and Deployment to run image prep from Agent Administrator tools and capture the image in WinPE. Review the resulting image version.
4. Configure a deployment profile, including any required drivers.
5. Deploy the image to the test computer. Deployment can overwrite the destination disk.
6. Check imaging tasks and verify that the destination boots and has working storage and network drivers.
