# First-time setup — Create first administrator

Login opens this page automatically while the database has no application users. If any application user already exists, first-time creation is unavailable. This is not a test for whether an administrator remains.

<div class="ui-controls-spacer"></div>

**Username**

Name for the initial application administrator.

**Password**

Initial password; resolve any password-validation errors before retrying.

**Create**

Creates the administrator with lockout enabled, then proceeds to sign-in. This account is separate from the Windows service account.

The first-administrator page is not an account-recovery or password-reset tool. Once initial creation is unavailable, use normal sign-in and an existing administrator account.
