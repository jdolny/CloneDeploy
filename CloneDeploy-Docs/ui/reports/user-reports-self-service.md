# Self Service

Report accepted self-service policy runs across users and devices. An accepted request does not establish successful execution; awaiting result means completion has not been reported.

<div class="ui-controls-spacer"></div>

**Recorded username / Username matching**

Enter a name and choose Contains or Equal. Matching ignores case; domain-qualified forms remain separate. Leave blank for all recorded users. Wildcards are not supported.

**User SID (exact match)**

Match a specific recorded user identity.

**Policy name contains / Result**

Filter the policy and reported outcome.

**Date range (UTC)**

Restricts the recorded acceptance dates, including the whole through date.

**Include archived devices**

Includes retained records for archived devices.

**Choose columns**

Select and reorder the information to display and export.

**Run report**

Previews up to 100 matching runs.

**Export all matches**

Exports all current matches, independent of preview paging.

**Save Report**

Saves filters and columns privately. Saving an opened report updates it; Save as a new copy with a different name retains the original.

**View Result**

Opens reported details and the policy version. Rejected requests are not retained; runs can disappear when their underlying device or policy is deleted.


**Report name / Save as a new copy (save dialog)**

Name is required, up to 200 characters. Save Report stores the current report definition; for an opened report, Save as a new copy creates another definition instead of updating it. Cancel leaves the stored report unchanged.

## Permissions

User report permission is required. Device and policy links require access to those records.
