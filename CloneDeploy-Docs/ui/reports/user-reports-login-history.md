# Login History

Find devices associated with recorded usernames. Each row represents a username/device pair, not a currently active session.

<div class="ui-controls-spacer"></div>

**Recorded username / Username matching**

Enter a name and choose Contains or Equal. Matching ignores case; domain-qualified forms remain separate. Leave blank for all recorded users. Wildcards are not supported.

**Date range (UTC)**

Restricts the recorded login dates, including the whole through date.

**Include archived devices**

Includes retained records for archived devices.

**Choose columns**

Select and reorder the information to display and export.

**Run report**

Previews up to 100 matching username/device pairs.

**Export all matches**

Exports all current matches, independent of preview paging.

**Save Report**

Saves filters and columns privately. Saving an opened report updates it; Save as a new copy with a different name retains the original.

**Report name / Save as a new copy (save dialog)**

Enter a required name up to 200 characters. Save Report stores the current filters and ordered columns; when editing an existing report, Save as a new copy creates another definition. Cancel leaves the saved report unchanged.

## Permissions

User report permission is required. Device and policy links require access to those records.
