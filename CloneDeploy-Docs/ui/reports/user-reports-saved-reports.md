# Saved Reports

Open private saved user report definitions. Each execution reads current data rather than retaining a fixed result snapshot.

<div class="ui-controls-spacer"></div>

**Search saved reports**

Find a definition by name.

**Name**

Opens the saved filters and columns in the appropriate report tab.

**Report type**

For user reports, identifies Login History or Self Service. Device report definitions use the Report tab.

**Delete**

Removes the definition without removing devices or underlying history.

## Permissions

User report permission is required.
