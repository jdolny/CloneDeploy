# Policy reports

Compare reported agent outcomes for policies. Counts are unavailable when a policy has no reportable version or reporting is disabled.

<div class="ui-controls-spacer"></div>

**Search policies**

Find policies by name.

**Include inactive and archived**

Include those policy states in the report.

**Agents / Result counts**

Select a count to inspect the associated devices.

**View**

Opens execution history for the selected policy.


**Search devices / Close (result dialog)**

Selecting a result count opens its matching devices and reported runs. Search filters the loaded rows. Device/user identity, result, start/finish times, version hash and details are read-only. Close does not retry or cancel a run.

## Permissions

Policy report permission is required.
