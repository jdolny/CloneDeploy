# Device reports

Build device reports using dynamic-group matching rules and a chosen set of columns. Preview matches and export device information to CSV, with one row per device.

<div class="ui-controls-spacer"></div>

**Device Stats**

Inspect a snapshot of non-archived devices.

**Report**

Define filters and choose the information to export.

**Saved Reports**

Open private saved device report definitions.

## Permissions

Device report permission is required.
