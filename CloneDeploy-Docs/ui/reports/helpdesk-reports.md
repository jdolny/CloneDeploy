# Help Desk reports

Compare ticket activity during a period with the current open workload. Period totals and current-open totals refer to different populations.

<div class="ui-controls-spacer"></div>

**From (UTC) / Through (UTC)**

Set the reporting period.

**Queue / Category / Technician / Status**

Narrow the report to the relevant assignments and states.

**Run report**

Applies the filters and refreshes results.

**Created / Closed / Open now**

Review period activity separately from current workload.

**Breakdowns**

Inspect results by queue, technician, category and age.

**Export CSV**

Exports using the applied report filters.

**Subject**

Opens a ticket conversation when your ticket scope permits it.

## Permissions

Help Desk report permission is required. Ticket access follows your separate Help Desk permissions.
