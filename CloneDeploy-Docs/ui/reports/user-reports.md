# User reports

Open **Reports > Users > Device History** to find devices associated with recorded usernames. Report types use tabs on this page.

<div class="ui-controls-spacer"></div>

**Saved Reports**

Open private saved user report definitions.

**Self Service**

Report accepted self-service policy runs across users and devices.

**Login History**

Find devices associated with recorded usernames.

## Permissions

User report permission is required.
