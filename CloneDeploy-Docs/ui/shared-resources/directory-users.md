# Users

Search synchronized identities used by login-policy targeting and self-service. These are not application sign-in accounts.

<div class="ui-controls-spacer"></div>

**Directory users**

An empty list can mean synchronization has not run, or that configured search bases do not include user OUs.

**Directory**

Restricts results to one configured directory connection.

**Search directory users**

Matches name, account, UPN, email, SID or directory path.

**Refresh directory users**

Reloads imported identities. Use the directory connection’s Sync now to fetch changes from AD.

## Permissions

Administrator access is required.
