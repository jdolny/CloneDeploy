# Windows Update reporting and approval

Approval is global for a reported revision; it does not install updates or change their source.

<div class="ui-controls-spacer"></div>

**Updates**

A valid update ID and revision are required for approval/testing. Counts reflect latest device inventory.

**Auto-Approve Rules**

Rules evaluate inventoried revisions on a schedule, normally every five minutes. Policies/actions still control installation.

## Permissions

Access requires Report Windows Updates permission.
