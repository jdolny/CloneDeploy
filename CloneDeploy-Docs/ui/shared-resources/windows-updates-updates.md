# Updates

A valid update ID and revision are required for approval/testing. Counts reflect latest device inventory.

<div class="ui-controls-spacer"></div>

**Search / status tabs / filters**

Narrows reported updates.

**Approve selected**

Approves up to 1,000 selected revisions. Newer revisions require approval again.

**Remove approval**

Revokes approval and blocks automatic reapproval of that revision.

**Allow auto-approval**

Removes the revision’s auto-approval block.

**Test selected updates**

Deploys only chosen revisions to selected devices without global approval changes.

**Refresh**

Reloads reporting; does not scan devices.

## Permissions

Access requires Report Windows Updates permission.
