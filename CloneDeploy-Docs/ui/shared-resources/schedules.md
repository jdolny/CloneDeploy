# Shared schedules

Reusable schedules for server jobs and scheduled content checks. Agent policy timing is configured on the policy instead.

<div class="ui-controls-spacer"></div>

**Search and manage**

Search the list and open an entry to edit it.

**New**

Opens the editor for a new entry.

**Search / column filters / paging**

Narrows the displayed records.

**Delete / Delete selected**

Requests removal after confirmation. References may prevent removal; review consuming configuration first.

**Editor**

Reusable schedules for server jobs and scheduled content checks. Agent policy timing is configured on the policy instead.

**Name / Description**

Identifies the schedule in selection controls.

**Schedule type**

Selects the supported schedule pattern.

**Every / Unit**

For interval scheduling, chooses the repeat interval with a minimum of five minutes.

**Starting on / At**

Uses the server’s time zone displayed in the dialog. Intervals repeat at fixed elapsed durations from this start.

**Create / Save**

Saves the reusable schedule; assign and enable it on the consuming task.

**Cancel**

Discards changes and closes the dialog.

**Weekly schedule**

Weekly schedules run on selected weekdays at the chosen time.

**Schedule type**

Choose Weekly for weekdays and a clock time; Interval for fixed elapsed repetition.

**Occurs on**

Select one or more weekdays.

**At / OK / Cancel**

Choose a time and accept it, or discard changes in the time picker.

**Time format**

Changes the picker between twelve-hour and twenty-four-hour display; does not change the scheduled instant.

**Create / Save**

Persists the schedule.

**Cancel**

Closes without saving the schedule.

## Permissions

Access requires Schedule View permission.
