# Help Desk

Review Help Desk history for the selected directory user.

<div class="ui-controls-spacer"></div>

**Recorded entries**

Review the retained Help Desk records matched to this directory identity.

**Paging**

Browse further retained records.

**Subject**

Opens the request conversation, subject to your ticket access.

## Permissions

Administrator access is required. Ticket visibility also follows Help Desk permissions.
