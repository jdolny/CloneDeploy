# Self-service categories

Organize policies shown in the agent portal. Category membership is presentation, not permission to run a policy.

<div class="ui-controls-spacer"></div>

**Search and manage**

All categories appear in portal display order. Open an entry to edit it.

**New**

Opens the editor for a new entry.

**Up / down arrows**

Moves a category one position and saves immediately. New categories appear at the end.

**Delete / Delete selected**

Requests removal after confirmation. References may prevent removal; review consuming configuration first.

**Editor**

Organize policies shown in the agent portal. Category membership is presentation, not permission to run a policy.

**Name / Icon**

Label and built-in icon shown to portal users.

**Create / Save**

Stores the category; assign policies through their self-service settings.

**Cancel**

Discards changes and closes the dialog.

## Permissions

Access requires Self Service Category View permission.
