# Self Service

Review self-service history for the selected directory user.

<div class="ui-controls-spacer"></div>

**Recorded entries**

Review the retained self-service records matched to this directory identity.

**Paging**

Browse further retained records.

**View Result**

Opens reported details and the policy version. Matches use the user SID and include archived devices; no SID means the history cannot be matched. Accepted does not imply completed successfully.

## Permissions

Administrator access is required.
