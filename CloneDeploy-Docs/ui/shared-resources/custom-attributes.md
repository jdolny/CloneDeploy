# Custom attributes

Define additional administrator-maintained values displayed on device records. This is separate from script-collected custom inventory.

<div class="ui-controls-spacer"></div>

**Search and manage**

Search the list and open an entry to edit it.

**New**

Opens the editor for a new entry.

**Search / column filters / paging**

Narrows the displayed records.

**Delete / Delete selected**

Requests removal after confirmation. References may prevent removal; review consuming configuration first.

**Editor**

Define additional administrator-maintained values displayed on device records. This is separate from script-collected custom inventory.

**Name / Description**

Identifies the attribute and explains the value to maintain.

**Create / Save**

Stores the definition; assign values from the corresponding device tab.

**Cancel**

Discards changes and closes the dialog.

## Permissions

Access requires Custom Attribute View permission.
