# Managed Credentials

Store reusable credentials for authorized operations such as domain join, Run As, directory synchronization and SMB access. Referencing a credential does not grant the account permissions on the remote system.

<div class="ui-controls-spacer"></div>

**Search and manage**

Search the credential list and open an entry to edit it.

**New managed credential**

Opens the credential dialog.

**Delete / Delete selected**

Requests deletion after confirmation. Remove dependent configuration first when the app reports references.

**Credential editor**

Provide credentials for the intended operation and account scope.

**Name**

Descriptive name displayed in credential pickers.

**Username**

Account name in the format expected by the destination, such as a domain-qualified account.

**Password**

Secret for the account. Existing passwords are not displayed; leave the password blank while editing to retain the saved secret.

**Create / Save**

Stores the credential for subsequent authorized operations.

**Cancel**

Discards edits.

## Permissions

Administrator access is required.
