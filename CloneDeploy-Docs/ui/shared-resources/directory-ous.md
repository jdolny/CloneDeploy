# OUs

Browse LDAP directory hierarchy and contents. This tab is available for full LDAP synchronization. Data reflects the latest successful sync; browsing does not synchronize the directory.

<div class="ui-controls-spacer"></div>

**Name / Type / Object ID**

Identify the imported directory object.

**Search and paging**

Find and browse the imported records using available list controls.

**Open item**

Select an available name to inspect its saved details.

## Permissions

Administrator access is required.
