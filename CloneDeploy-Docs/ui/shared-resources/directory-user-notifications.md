# Notifications

Review notification deliveries and acknowledgments matched to this directory identity.

<div class="ui-controls-spacer"></div>

**Notification / Device**

Identify the notice and the device that reported it. Device links require separate device access.

**Status**

Distinguishes pending acknowledgment, acknowledgment here or elsewhere, and expiration.

**Delivered / Expires / Acknowledged**

Review reported event times in local time. Missing dates are displayed as a dash.

**View**

Opens the recorded notification text.

**Refresh**

Reloads recorded receipts.

**Paging**

Loads further retained receipts.

## Permissions

Administrator access is required.
