# WinGet catalog settings

Import package metadata used by WinGet action selection. Catalog import does not install packages on devices.

<div class="ui-controls-spacer"></div>

**Catalog**

Save the source before requesting an import. Use Task Scheduler for recurring imports.

**Manifest ZIP URL**

URL of a WinGet repository ZIP containing a manifests directory. Import includes versions, installer scope and English descriptions.

**Save settings**

Saves the catalog source URL.

**Import now**

Downloads and imports the saved source.

**Configure schedule**

Opens scheduling configuration.

**Refresh / Retry**

Reloads import status or retries loading this page.

**Latest import**

Shows the latest completion state/time; it is not a device deployment result.
