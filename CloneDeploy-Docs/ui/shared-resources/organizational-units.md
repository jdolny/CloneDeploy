# Organizational Units

Browse imported directory locations and assign CloneDeploy policies. The tree reflects the latest successful directory sync, not a live directory query. These assignments do not edit Active Directory or its permissions.

<div class="ui-controls-spacer"></div>

**Directory connection**

Select the synchronized directory to browse.

**Search directory**

Find a location in the imported tree. Expand its nodes to browse descendants.

**Refresh directory**

Reloads imported tree data. Synchronize the directory connection separately to retrieve source-directory changes.

**Details / Contents**

Review the selected location and its direct child objects. Search contents narrows that list.

**Policies / Edit policies**

Review or change CloneDeploy assignments for the selected location.

**Include descendant locations**

Extends an assignment to child locations.

**Save Policies**

Saves the CloneDeploy policy assignments.

**Select / Cancel**

In picker mode, returns the selected OU to the calling editor or closes without changing its selection.

## Permissions

Administrator access is required.
