# General

Inspect the synchronized directory identity. Make identity changes in the source directory. A warning appears when the user was absent from the latest sync.

<div class="ui-controls-spacer"></div>

**Name / Account / User principal name / Email / Account status**

Review the imported identity and enabled or disabled state.

**Directory / SID / Object ID / Directory path / Last seen in directory sync**

Identifies the source, immutable account identifiers, directory location and most recent observed synchronization.

## Permissions

Administrator access is required.
