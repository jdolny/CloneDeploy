# Groups

Review groups imported by the selected directory connection. Data reflects its last successful synchronization.

<div class="ui-controls-spacer"></div>

**Name**

The imported object name. Group and computer names are read-only in this list.

**Object GUID / Entra object ID**

The source-directory identifier appropriate to the provider.

**Account**

The imported account name.

**Search**

Filter the imported group records.

**Refresh synced data**

Reloads saved directory data without starting a directory synchronization.

**Paging**

Browses imported records.

## Permissions

Administrator access is required.
