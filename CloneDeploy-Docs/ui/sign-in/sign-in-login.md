# Login

Sign in with an application account. On an installation with no application users, this page redirects to first-administrator setup.

<div class="ui-controls-spacer"></div>

**Username / Password**

Enter your application credentials. Directory inventory records do not by themselves grant application access.

**Sign in**

Validates the password and proceeds to MFA when required. Failed attempts may lock an account. Password sign-ins use a browser session; there is no Remember me option.

**Sign in with Microsoft**

Appears when Microsoft sign-in is enabled. Continues through the configured identity provider; mapped access and tenant requirements still apply.
