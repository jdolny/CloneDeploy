**Confirmation dialogs**

Destructive or disruptive actions display the operation and affected records before the final confirmation. Review that text, then use the named action to submit it or Cancel to leave without submitting. A confirmation does not configure a reusable setting. After an operation has been accepted, closing its result does not roll it back.
