# Custom Inventory

Review the saved output of inventory scripts assigned to this device. Changing a script does not immediately update existing results.

<div class="ui-controls-spacer"></div>

**Inventory script**

The script action associated with the collected result.

**Value**

The value returned by the inventory script. It is read-only here.

**Column filters and paging**

Filter script names and browse the saved results. The Value column does not support column filtering.

## Permissions

Device View is required to open the device.
