# Notifications

Review the latest 200 notification acknowledgment receipts. Delivery and acknowledgment are different events. Synced directory users acknowledge once across devices; local or unmatched accounts remain device-specific.

<div class="ui-controls-spacer"></div>

**Notification**

The recorded notification title.

**User / Windows SID**

The associated username and Windows identity. Awaiting a user session indicates no user has yet been associated with the receipt.

**Status**

Distinguishes pending acknowledgment, acknowledgment here or on another device, and expiration. Expiration stops reminders without deleting the history.

**Delivered / Acknowledged / Expires**

The recorded delivery, acknowledgment and expiry times.

**Refresh**

Reloads notification receipts.

**Paging**

Browses loaded receipts. A missing receipt does not prove that a notification was never displayed.

## Permissions

Device View is required to open the device.
