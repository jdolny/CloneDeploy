# Policies

Maintain policies assigned through this group. Removing an assignment here leaves any direct, other-group or OU assignments in place.

<div class="ui-controls-spacer"></div>

**Policy**

Select a policy name to open it.

**Execution priority**

The policy execution priority shown for the assignment.

**Search**

Filter the assigned-policy list.

**Edit assigned policies**

Opens the policy picker. Search and add or remove policies, or drag them between the available and selected lists.

**Save Policies**

Commits the group assignments. Cancel discards the picker changes.


**Search policies / Include descendant locations / Apply selection**

Search filters available policies in the picker. Include descendant locations is shown when this shared picker is used for directory-location assignments; it controls propagation below that location, not device-group membership. Save Policies commits group changes; Apply selection returns pending choices when embedded in another editor. Cancel discards picker edits.

## Permissions

Device Group View is required to open the group. Device Group Edit is required to save changes.
