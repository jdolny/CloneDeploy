# Policies

Review reported policy runs and their outcomes: succeeded, failed, skipped, not applicable or awaiting result.

<div class="ui-controls-spacer"></div>

**Policy**

The policy associated with the run.

**Started**

The recorded start time in local time.

**Result**

The reported execution outcome. Awaiting result means completion has not been reported.

**View result**

Shows result details and the configuration hash identifying the policy version. Closing the dialog does not retry the policy.

**Refresh**

Reloads reported runs.

**Paging**

Browses the retained runs returned for this device.

## Permissions

Device View is required to open the device.
