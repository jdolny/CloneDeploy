# Processes

Inspect a process snapshot from a connected Windows endpoint. This tool is not shown for macOS devices. Protected or exited processes may have unavailable details.

<div class="ui-controls-spacer"></div>

**Process / PID**

The process name and identifier. Check both before ending a process.

**CPU time**

Cumulative processor time since the process started, not its current CPU percentage.

**Memory**

Reported memory use in MiB.

**Search processes**

Filters the loaded snapshot.

**Refresh**

Collects current process details.

**End process**

Terminates the selected process after confirmation. Unsaved work can be lost. Protected or system processes and entries without a start identity cannot be ended here.

## Permissions

Device View is required to open the device. Device Processes is required to inspect and manage processes.
