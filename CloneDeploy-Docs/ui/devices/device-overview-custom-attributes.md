# Custom Attributes

Maintain values for shared custom-attribute definitions. These manually maintained values are separate from script-collected inventory.

<div class="ui-controls-spacer"></div>

**Attribute**

The shared definition that identifies each value.

**Value**

Enter the value for the attribute. Not set indicates an empty value.

**Save changes**

Saves the edited values for this device.

## Permissions

Device View is required to open the device. Device Edit is required to save values. Custom Attribute View loads all shared definitions; without it, the page uses definitions already associated with this device's saved values.
