# Group Members

Review the devices currently included in the group. Manual and dynamic groups retain their saved membership; All Devices automatically includes enrolled, non-archived devices.

<div class="ui-controls-spacer"></div>

**Name / Device ID**

Identify each member. Select its name to open the device.

**Search**

Filter the displayed members.

**Edit members**

For manual groups, opens a two-list picker. Search devices finds available devices, then add, remove or drag devices between lists. The available search returns up to 100 matches. Save Members commits the list; Cancel discards edits.

**Edit dynamic criteria**

For dynamic groups, define conditions with AND, OR and NOT groups. Conditions in the same inventory category apply to the same inventory record.

**Preview**

In the criteria editor, preview up to 100 matching devices without changing saved membership.

**Save**

Saves the dynamic query used to evaluate membership. Unsaved preview criteria do not replace the saved query.

**Recalculate members**

Queues evaluation of the saved dynamic criteria using current stored data. Wait for evaluation to complete before treating the member list as current.

**Column filters and paging**

Narrow and browse the displayed members.

## Permissions

Device Group View is required to open the group. Device Group Edit is required to save changes.
