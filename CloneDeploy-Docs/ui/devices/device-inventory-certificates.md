# Certificates

Inspect certificate information reported by the Windows agent. This page does not issue, revoke or install certificates.

<div class="ui-controls-spacer"></div>

**Subject**

The identity to which the certificate was issued.

**Issuer**

The authority that issued it.

**Store**

The certificate store reported by the endpoint.

**Friendly name**

The display name recorded for the certificate, when available.

**Thumbprint**

The fingerprint identifying the certificate.

**Serial**

The serial number assigned by the issuer.

**Valid from / Expires**

The certificate validity period, displayed in local time. An unavailable date appears as a dash.

**Search**

Match certificate identity, store, friendly name, serial number, thumbprint or displayed date information.

**Column filters and paging**

Use the available column filters to narrow the loaded records, and the pager to browse them. Filtering does not request a fresh inventory collection.

## Permissions

Device View is required to open the device.
