# Overview

Review the device record and maintain administrative information independently of collected inventory.

<div class="ui-controls-spacer"></div>

**General**

Review identity, enrollment, check-in and directory information. Edit the description and tags when permitted.

**Custom Attributes**

Maintain values for shared custom-attribute definitions. These values are separate from inventory-script results.

**Comments**

Append dated operator notes. Existing comments cannot be edited or deleted.

**Attachments**

Upload supporting files and download files already linked to the device.

## Permissions

Device View is required to open the device.
