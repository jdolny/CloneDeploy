# Help Desk

Review support requests associated with this device. The list is limited by your Help Desk access.

<div class="ui-controls-spacer"></div>

**Request / Subject**

Identify a ticket. Select its subject to open the conversation and current details.

**Status**

The current ticket status.

**Requester**

The user who submitted the request.

**Category / Queue / Assigned to**

The recorded categorization, routing queue and staff assignment.

**Updated**

The latest update time, displayed in local time.

**Refresh**

Reloads the list.

**Paging**

Loads further requests you are permitted to view.

## Permissions

Device View is required to open the device. Help Desk access and ticket scope determine which requests you can open.
