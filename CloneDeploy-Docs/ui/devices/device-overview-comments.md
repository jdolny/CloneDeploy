# Comments

Keep dated notes about the device. Comments are appended to its history and cannot be edited or deleted.

<div class="ui-controls-spacer"></div>

**Added / Author / Comment**

Review when a note was added, who wrote it and its text.

**Add comment**

Opens the editor. Enter the note and submit it to append the comment, or select Cancel to discard it.

**Paging**

Browse recorded notes without changing them.


**Comment / Cancel (comment dialog)**

Enter the text to append, then select Add comment. Cancel discards the text. Successful submission creates an immutable note; it does not update an earlier comment.

## Permissions

Device View is required to open the device. Device Edit is required to add comments.
