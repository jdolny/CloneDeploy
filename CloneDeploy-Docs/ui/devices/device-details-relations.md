# Relations

Inspect saved connections between the device and other records. Relations describe configuration, not proof that a policy ran.

<div class="ui-controls-spacer"></div>

**Search relations**

Filter the relationship list by displayed information.

**Type**

The category of related item. Use the type chips to narrow the list.

**Related item**

Select an available item link to open it.

**Connection**

Explains how the item is connected to this device.

**Included by**

Shows the policy or assignment that introduces a related item.

**Refresh**

Reloads saved relations.

## Permissions

Device View is required to open the device. Directory relations and linked records require their respective access permissions.
