# Actions

Review the latest 100 direct action deployments for this device, including queued and running work. A task without a reported result has not been confirmed successful.

<div class="ui-controls-spacer"></div>

**Action / Status**

The requested action and its current recorded task state.

**Requested by / Source**

The requester and origin of the task.

**Queued / Started / Finished**

Recorded task times, displayed in local time. Work that has not reached a stage has no timestamp for it.

**View result**

Opens the reported outcome and output, with requester and queued-time context. Close the dialog to return; viewing does not rerun the task.

**Refresh**

Reloads recorded tasks.

**Column filters and paging**

Narrow and browse the loaded subset of tasks.

## Permissions

Device View is required to open the device.
