# Inventory

Review the last inventory received from the agent. This is stored information; missing data means unknown, not disabled. Request Inventory now from Connect when a new collection is needed.

<div class="ui-controls-spacer"></div>

**System Info**

Review hardware, operating system, network and storage information, plus the security and update details reported by the endpoint.

**Software**

Review installed applications and reported versions. Supported Windows applications can be queued for uninstall with the required permission.

**Windows Updates**

Review the updates reported by a Windows endpoint. Viewing inventory does not approve or install updates.

**Certificates**

Inspect reported certificate identities, stores and validity dates. This subtab is available for Windows endpoints.

**Custom Inventory**

Read the saved results of custom inventory scripts.

**User Logins**

Review recorded login and logout history. Stored history does not establish who is connected now.

## Permissions

Device View is required to open the device.
