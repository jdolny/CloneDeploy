# Imaging

Manage the Windows imaging defaults and review imaging events recorded for this device. This tab is not available for macOS devices.

<div class="ui-controls-spacer"></div>

**Deployment Settings**

Set the default image and deployment profile, or inherit the pair from device groups. Saving defaults does not start deployment.

**Imaging Logs**

Review recorded capture, deployment and setup events. Open a log to inspect its reported details.

## Permissions

Device View is required to open the device.
