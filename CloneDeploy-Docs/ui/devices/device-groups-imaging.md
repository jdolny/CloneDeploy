# Imaging

Provide imaging defaults for group members that have no device override. Saving group defaults does not deploy an image or overwrite individual device assignments.

Applicable groups must agree on the image and profile. Conflicting or incomplete pairs block inheritance; groups have no imaging priority. A device shows its effective saved assignment and source on Deployment Settings.

<div class="ui-controls-spacer"></div>

**Image**

Select an enabled Windows image to provide to members.

**Deployment profile**

Select an enabled deployment profile to accompany the image.

**Save changes**

Saves the pair. Assign both fields or clear both to stop providing defaults. Devices with their own image and profile keep that override.

## Permissions

Device Group View is required to open the group. Device Group Edit is required to save changes.
