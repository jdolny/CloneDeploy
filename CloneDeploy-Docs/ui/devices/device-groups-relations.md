# Relations

Inspect member devices, assigned policies, referenced actions, tags and imaging defaults. These are saved relationships, not confirmation that a policy will execute on every member. Archived devices are excluded; All Devices uses its current automatic membership.

<div class="ui-controls-spacer"></div>

**Search relations**

Filter the displayed relationships.

**Type**

Use the type chips to narrow the list. Policy entries distinguish published, unpublished and archived assignments.

**Related item**

Select an available link to open the item.

**Connection**

Explains its association with the group.

**Included by**

Shows which policies introduce the related action or condition. Shared actions are listed once with all referring policies.

## Permissions

Device Group View is required to open the group. Linked records require their respective viewing permissions.
