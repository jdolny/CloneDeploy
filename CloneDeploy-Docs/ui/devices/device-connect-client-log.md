# Agent log

Read recent output from the connected agent. Entries use UTC. The viewer is not the full server log.

<div class="ui-controls-spacer"></div>

**Filter log**

Narrow the displayed entries by text.

**Pause / Resume**

Stop or resume automatic refresh, normally about every three seconds. This changes the viewer, not agent execution.

**Refresh**

Request current log entries immediately.

**Download full log**

Downloads the complete current agent.log regardless of the viewer filter. Rotated archives are not included. Requires an updated, connected agent.

## Permissions

Device View is required to open the device.
