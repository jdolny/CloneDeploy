# User Logins

Review recorded user sessions, initially listed by most recent login. Use Connect for current session information.

<div class="ui-controls-spacer"></div>

**User**

The username recorded for the session.

**Logged in**

The reported login time, displayed in local time.

**Logged out**

The recorded logout time. Still logged in means no logout has been recorded; it does not prove the session is currently active.

**Column filters and paging**

Filter the User column and browse saved sessions. Login and logout date columns do not support column filtering.

## Permissions

Device View is required to open the device.
