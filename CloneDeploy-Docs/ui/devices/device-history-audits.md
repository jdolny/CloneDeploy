# Audits

Review administrative events associated with this device, newest first. Events are matched by recorded device IDs, GUIDs and task references, so a rename does not discard their association. Historical events without a recorded reference cannot be reconstructed from a name or current group membership.

<div class="ui-controls-spacer"></div>

**Date / User**

When the event was recorded, in local time, and the user responsible.

**Operation / Category**

The action performed and its recorded category.

**Object / Details**

The affected item and event metadata. Raw configuration payloads are not displayed.

**Search**

Find events by user, operation, category, object or details.

**Refresh**

Reloads recorded events.

**Paging**

Browses all matching retained events.

## Permissions

Device View is required to open the device.
