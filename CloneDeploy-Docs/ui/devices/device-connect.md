# Connect

Open the connection panel to work with the enrolled agent. Live tools require a connected agent, supported endpoint features and the permission for each operation.

<div class="ui-controls-spacer"></div>

**Status and sessions**

Review connection state, uptime and the current session snapshot. Check the snapshot time; stored inventory is separate.

**Check in now**

Requests a check-in without changing the regular interval.

**Inventory now**

Requests a new inventory collection. View inventory opens saved results after acknowledgment; collection may still need time to complete.

**Deploy image through agent**

Opens a deployment review for supported Windows devices. Queuing imaging can reboot the device and overwrite its operating system.

**Reboot / Shutdown**

Requests the power operation after confirmation. Unsaved user work can be lost.

**Full screen / Close**

Resize or close the panel. Closing ends its interactive terminal and remote-viewing sessions.

**Agent log**

Read recent agent log output and download the current full log when permitted.

**Terminal**

Start an interactive privileged shell.

**Services / Processes**

Inspect service or process snapshots and request permitted operations. These tabs are shown for Windows endpoints.

**Remote viewing**

Start a remote screen session, subject to the effective consent rule and endpoint permissions.

## Permissions

Device View is required to open the device. Check-in, inventory, imaging through agent, power actions and each remote tool require their own device permissions.
