# History

Review audit events recorded directly against the group, newest first. Member-device history and unrelated policy activity are not included. Earlier changes without a group audit record cannot be reconstructed.

<div class="ui-controls-spacer"></div>

**Date / User**

The local display time and user associated with the event.

**Operation / Object / Details**

The recorded action, affected object and explanatory metadata. Events can include settings, membership, policy and imaging changes, wake requests and scheduled power results.

**Search**

Find events by the displayed metadata.

**Paging**

Browses retained history.

## Permissions

Device Group View is required to open the group.
