# Windows Updates

Review update information reported by this Windows endpoint. This inventory does not approve, download or install an update.

<div class="ui-controls-spacer"></div>

**Title / Category**

The update name and classification reported by Windows Update.

**Update ID**

The identifier of the update.

**KB articles**

Open a Microsoft article associated with the update when a link is available.

**Observed revision**

The revision reported by this endpoint, which may differ from another device or a later catalog revision.

**Type / Severity**

The reported update type and security severity, when supplied.

**Downloaded / Hidden / Optional / Installed**

Reported state at collection time. Missing observations should not be interpreted as a positive or negative state.

**Deployment changed**

The reported deployment-change time, displayed in local time when available.

**Search**

Filter the saved update list using the reported update details.

**Column filters and paging**

Use the available column filters to narrow the loaded records, and the pager to browse them. Filtering does not request a fresh inventory collection.

## Permissions

Device View is required to open the device.
