# General

Review device identity and enrollment information, then maintain its administrative description and tags. Identity and directory fields are read-only here.

<div class="ui-controls-spacer"></div>

**Name**

The device record name. Use the device rename action to request a name change.

**Enrollment status**

The current state of the device record, such as enrolled, pre-created or archived.

**Device GUID**

The unique CloneDeploy device identifier.

**Last check-in / Last inventory**

The latest recorded check-in and inventory collection times. Neither guarantees a live connection.

**Enrolled / Archived**

The recorded enrollment and archive times, when applicable.

**Last IP address**

The last IP address recorded for the device.

**Agent platform / Agent version**

The platform and version reported by the enrolled agent.

**Installation ID / Hardware UUID / Imaging MAC**

Identifiers used to associate the installation and hardware with the device record.

**Directory source / Directory account / Directory path / Directory account disabled**

Imported directory identity and disabled state. Change directory data in its source and synchronize it.

**Description**

Enter an administrative description for this device.

**Add tag**

Choose a shared tag. Remove a tag chip to remove it from the pending selection.

**Save changes**

Saves the description and selected tags.

## Permissions

Device View is required to open the device. Device Edit is required to save changes. Tag View is required to load available tags.
