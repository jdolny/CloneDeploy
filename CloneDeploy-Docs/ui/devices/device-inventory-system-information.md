# System Info

Review the last hardware, operating system and security information reported by the endpoint. Missing data is unknown, not disabled. Available sections depend on platform and collected inventory; these are read-only observations.

<div class="ui-controls-spacer"></div>

**Manufacturer / Model / Name**

The computer manufacturer, hardware model and reported computer name.

**Domain / Workgroup**

The domain or workgroup reported by the endpoint.

**Memory (MB)**

Reported memory capacity in megabytes.

**Operating system / Version / Build / Architecture / Release**

The installed operating system identity and native architecture, when reported.

**UAC status / Time zone / Update server**

Reported Windows account-control state, local time zone and configured update server.

**Serial number / BIOS version / SMBIOS version**

The serial and firmware information supplied by the hardware.

**Processor / Speed (MHz) / Cores**

Processor identity, reported clock speed in megahertz and core count.

**Graphics adapter / Memory (MB)**

Reported graphics hardware and its memory capacity.

**Product / Provider / Real-time scanner / Definitions**

The antivirus product and its reported protection and definition state.

**Domain profile enabled / Private profile enabled / Public profile enabled**

The reported enabled state of each Windows Firewall profile.

**Drive / Reported status code**

The BitLocker volume and raw reported status. This page does not change encryption or expose recovery actions.

**Reported default update source / Last successful update search**

The source and time of the most recent successful Windows Update search.

**Restart required**

Whether the reported update state requires a restart.

**Download behavior / Installation schedule / Automatic restart protection**

Summaries of observed Windows Update configuration. These do not change the update policy.

**Reported settings**

Read each update setting, reported value, source and associated Group Policy when provided.

**Last observed installation success / Last observed successful download / Most recent observed failure**

Reported update activity and failure details. These times do not establish that every update is installed.

**Network adapters**

Reported adapter name, MAC and IP addresses, gateways, status and speed in bits per second.

**Physical disks**

Reported disk model, serial, firmware, size in MB and status.

**Volumes**

Reported drive, size and free space in GB, and free-space percentage.

**Printers**

Reported printer names, drivers, local or network status and share names.

## Permissions

Device View is required to open the device.
