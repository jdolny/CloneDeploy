# Terminal

Run an interactive shell on the connected endpoint. Windows sessions run as NT AUTHORITY\SYSTEM; macOS sessions use root. Other agent operations may wait while the terminal is open.

<div class="ui-controls-spacer"></div>

**Shell**

Choose Windows PowerShell or Command Prompt on Windows, or Zsh (root) on macOS. Disconnect before changing the shell.

**Connect terminal**

Starts the chosen shell. Click inside the terminal to type.

**Ctrl+C / Ctrl+Shift+C**

Interrupt the running command or copy selected terminal text, respectively.

**Disconnect**

Ends the shell and its child processes. Closing the tab or panel also ends the session. Sessions expire after ten minutes without input or thirty minutes in total.

## Permissions

Device View is required to open the device. Device Terminal is required to use the terminal.
