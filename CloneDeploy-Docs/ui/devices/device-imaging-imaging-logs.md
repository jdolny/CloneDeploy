# Imaging Logs

Review imaging events recorded for this device to investigate capture, deployment and setup activity. Entries are initially listed newest first.

This tab shows saved log entries rather than live imaging progress. Use **Tasks → Imaging Tasks** to monitor running work or investigate deployment setup that needs attention. An empty list means no imaging history is recorded for this device; it does not confirm that an operation succeeded.

<div class="ui-controls-spacer"></div>

**Date**

When the event was recorded, displayed in your local time. A dash indicates that no valid date is available.

**Type**

The source or category of the event, such as Agent, Imager or Setup.

**Result**

The reported stage or outcome, such as Capture Completed, Deployment Failed or Retry. An entry can describe one stage of an operation rather than its final result.

**MAC address**

The MAC address stored with the log entry, when available.

**View log**

Opens the recorded details in a dialog, with the event's date, type and result shown above the log. Use **Close**, the close icon or Escape to return to the list. If the entry has no content, the dialog reports that no result was provided.

Viewing a log does not retry or change the operation.

**Column filters**

Narrow the list using the Type, Result or MAC address column filters. Date and Log do not support column filtering.

**Paging**

Move between pages of recorded events and adjust the number of rows shown per page.

## Permissions

Viewing the device and its imaging logs requires **Device View** permission.
