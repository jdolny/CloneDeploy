# Files

Upload ZIP/CAB or supported library content containing INF, CAT and SYS files. Preparation produces an imaging ZIP while retaining the original.

<div class="ui-controls-spacer"></div>

**Upload files**

Adds local content and prepares supported packages.

**Add from URL / Edit external file**

Sets URL, filename, optional SHA-256 and scheduled URL checks. Save and download starts retrieval.

**Download URL / File name**

Address to retrieve and the stored filename, including its extension.

**Check this URL on the profile's schedule**

Enables scheduled checks for this URL file; a pinned checksum disables refresh.

**Save and download / Cancel**

Saves and starts retrieval, or closes the external editor without saving.

**Expected SHA-256 (optional)**

Pins expected content and disables automatic URL refresh.

**Follow vendor releases**

Allows scheduled catalog replacements. Editing a vendor import as a direct URL stops catalog following.

**Download prepared ZIP / Download driver file**

Retrieves extracted imaging content or the original attachment.

**Retry attachment / Retry preparation**

Retries the failed stage. Previous successful content remains until replacement succeeds.

**Cancel download / Download again**

Stops a retrieval or requests another one.

**Refresh status / Search files**

Reloads progress or filters attachments.

**Delete driver file**

Removes selected content; ensure the pack still contains required drivers.


**Upload / Cancel remaining uploads**

Choose or drop up to 10 nonempty files, each no larger than 10 GiB, into the upload dialog. Remove unwanted file chips before starting, then select Upload. Progress identifies the current file and transferred percentage. Cancel remaining uploads stops outstanding transfers; completed uploads or attachments are not rolled back. Wait for attachment to complete before using uploaded content. The dialog's Close action dismisses it after active work finishes.

## Permissions

Access requires Driver Pack View permission.
