# Deployment

Choose the image and profile supplied when this hardware rule matches. Saving a rule does not start imaging.

<div class="ui-controls-spacer"></div>

**Image**

Select the source Windows image.

**Deployment profile**

Select the profile controlling its deployment.

**Save Changes**

Saves the deployment selection for the rule.

## Permissions

Deployment Rule View permits viewing; Deployment Rule Edit is required to save.
