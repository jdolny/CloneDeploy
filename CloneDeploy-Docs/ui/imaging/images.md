# Images

An image record identifies captured Windows content. Each completed upload creates a version; the active version is used for deployment.

Search names, include disabled images if needed, filter by tags, and open a name for its tabs.

<div class="ui-controls-spacer"></div>

**New Image**

Enter name, description and WIM/FFU type. This creates a record, not captured content.

**Tags / Match**

Matches any/all selected labels.

**Delete / Delete selected**

Requests removal after confirmation. Protected images cannot be deleted.


**Name / Description (New Image dialog)**

Enter a required image name up to 200 characters and an optional description.

**Image type**

Choose WIM (Windows partition) or FFU (whole disk). The choice defines the capture format for this image record; it does not upload disk content.

**Create / Cancel**

Create saves the image record. Cancel closes without creating one. Creating requires Image Edit permission.

## Permissions

Access requires Image View permission.
