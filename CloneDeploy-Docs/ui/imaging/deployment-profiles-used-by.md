# Relations

Devices using this profile as their default.

<div class="ui-controls-spacer"></div>

**Refresh / Search devices**

Reloads or filters references.

**Open device**

Opens its defaults for review.

Open **Relations** on an image, deployment profile, preparation profile, or driver pack to inspect related items.

Select a type chip to filter by relationship, or **All** for every loaded relation. **Search relations** narrows the list. The table shows the type, related item and connection; linked names open the related record. **Refresh relations** reloads the data and can retry a failed request. Paging browses matching rows.

This view inspects relationships. Change assignments in the corresponding configuration or related item.

## Permissions

Access requires Deployment Profile View permission.
