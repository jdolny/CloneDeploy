# Driver packs

Prepare Windows driver content and reuse it in deployment profiles or WinPE builds.

Search names, include disabled packs or filter by tags.

<div class="ui-controls-spacer"></div>

**New Driver Pack**

Creates name/description before adding content.

**Delete / Delete selected**

Requests removal; review references first.


**Name / Description (creation dialog)**

Enter a required name for the driver pack, up to 200 characters, and an optional description.

**Create / Cancel**

Create saves the driver pack and opens its configuration. It does not start a build, preparation or deployment. Cancel closes without creating it. Creation requires Driver Pack Edit.

## Permissions

Access requires Driver Pack View permission.
