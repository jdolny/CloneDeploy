# Matching

Define the hardware that matches this rule using reported manufacturer and model information.

<div class="ui-controls-spacer"></div>

**Use a model from inventory**

Populate the hardware criteria from a known inventory model.

**Exact manufacturer / Exact model**

Set literal manufacturer and model criteria.

**Manufacturer regex / Model regex**

Use regular expressions when a literal hardware identity is too narrow. Test against representative model strings.

**Save Changes**

Saves the criteria used for subsequent matching.

## Permissions

Deployment Rule View permits viewing; Deployment Rule Edit is required to save.
