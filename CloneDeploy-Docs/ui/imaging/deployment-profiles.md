# Deployment profiles

Profiles configure deployment behavior separately from the source image. One profile can be used with different images.

Find profiles by name; include disabled entries for maintenance.

<div class="ui-controls-spacer"></div>

**New Deployment Profile**

Creates a named profile with optional description.

**Delete / Delete selected**

Requests deletion after confirmation; review Used by first.


**Name / Description (creation dialog)**

Enter a required name for the deployment profile, up to 200 characters, and an optional description.

**Create / Cancel**

Create saves the deployment profile and opens its configuration. It does not start a build, preparation or deployment. Cancel closes without creating it. Creation requires Deployment Profile Edit.

## Permissions

Access requires Deployment Profile View permission.
