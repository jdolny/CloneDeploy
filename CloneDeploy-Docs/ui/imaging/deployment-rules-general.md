# General

Identify and enable this automatic deployment rule. Complete the deployment selection and hardware matching before using it.

<div class="ui-controls-spacer"></div>

**Name / Description**

Identify the rule and its intended hardware or deployment purpose.

**Enabled**

Controls whether the saved rule participates in automatic selection.

**Priority**

Orders rule evaluation; lower numbers take precedence.

**Save Changes**

Saves the General settings.

## Permissions

Deployment Rule View permits viewing; Deployment Rule Edit is required to save.
