# OU Naming Rules

Manage reusable, domain-scoped OU naming rules used during Windows deployment. A rule set selects a destination based on the final computer name.

<div class="ui-controls-spacer"></div>

**Search rule sets**

Find a saved rule set.

**Name / Domain / Enabled / Rules**

Review the set identity, directory domain, availability and rule count.

**New**

Creates a named rule set for later configuration.

**Delete**

Removes a rule set through the deletion flow. Review profile references before deleting.


**Name / Description (creation dialog)**

Enter a required name for the OU naming rule set, up to 200 characters, and an optional description up to 2,000 characters.

**Create / Cancel**

Create saves the OU naming rule set and opens its configuration. It does not start a build, preparation or deployment. Cancel closes without creating it. Creation requires OU Naming Rule Edit.

## Permissions

OU Naming Rule View permits listing and testing; OU Naming Rule Edit permits creation and changes.
