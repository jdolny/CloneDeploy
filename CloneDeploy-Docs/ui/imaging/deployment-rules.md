# Deployment rules

Maintain hardware-matching rules that select an image and profile in Imager. An explicitly queued deployment takes precedence over automatic matching.

<div class="ui-controls-spacer"></div>

**Search deployment rules**

Find saved rules.

**Include disabled**

Include rules that do not currently participate in matching.

**Name / Priority / Enabled**

Identify a rule and its ordering and availability.

**New Deployment Rule**

Create a named record, then configure its General, Deployment and Matching tabs.

**Delete**

Removes a saved rule after the deletion flow.


**Name / Description (creation dialog)**

Enter a required name for the deployment rule, up to 100 characters, and an optional description.

**Create / Cancel**

Create saves the deployment rule and opens its configuration. It does not start a build, preparation or deployment. Cancel closes without creating it. Creation requires Deployment Rule Edit.

## Permissions

Deployment Rule View is required to view rules; Deployment Rule Edit is required to change them.
