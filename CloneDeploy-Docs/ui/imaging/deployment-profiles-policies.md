# Post-deployment Policies

The agent runs these policies in order after imaging; per-deployment progress prevents repeating completed work after restart.

<div class="ui-controls-spacer"></div>

**Edit assigned policies**

Search/add/remove through the picker, then Apply selection.

**Move up / Move down**

Orders post-deployment execution.

**Remove policy**

Removes the assignment, not the policy.

**Save Policies**

Commits selection/order.

**Search**

Filters the displayed sequence.

## Permissions

Access requires Deployment Profile View permission.
