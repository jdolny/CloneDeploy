# Online Library

Browse vendor packs for the intended model, OS/build and architecture. Extracted size can greatly exceed download size.

<div class="ui-controls-spacer"></div>

**Manufacturer / Pack type / Load catalog**

Chooses a vendor and Windows/WinPE catalog and loads it.

**Model / Search packages**

Narrows available downloads.

**Follow newer releases**

Enables scheduled updates for this model/OS/architecture; otherwise retains this release.

**Add and download**

Attaches content and retrieves it in the background.

**WinPE use**

Preparation does not rebuild boot images. Lenovo’s listed catalog is Windows model packs; upload extracted WinPE drivers separately. Choose suitable boot drivers from Surface bundles.

## Permissions

Access requires Driver Pack View permission.
