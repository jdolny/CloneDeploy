# Models

Exact links and regex pairs are alternative hardware matches.

<div class="ui-controls-spacer"></div>

**Manufacturer / Add model / Remove model link**

Adds/removes exact inventory model matches.

**Manufacturer regex / Model regex**

Case-insensitive after trimming. Both fields in one pair must match when filled. Use `^` and `$` for whole-field matching.

**Add / Remove regex rule**

Changes alternative pairs.

**Preview matches / Search models**

Checks inventory matches without deploying.

**Save Models**

Commits rules used by consuming profiles.

## Permissions

Access requires Driver Pack View permission.
