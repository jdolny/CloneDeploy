# Pre-Sysprep Script

PowerShell runs as SYSTEM before staging the answer file and Sysprep, even if Run Sysprep is unchecked. A nonzero exit stops preparation.

<div class="ui-controls-spacer"></div>

**PowerShell commands**

Preparation logic; do not restart or shut down from it.

**Save Profile**

Stores the script.

## Permissions

Access requires Image Prep Profile View permission.
