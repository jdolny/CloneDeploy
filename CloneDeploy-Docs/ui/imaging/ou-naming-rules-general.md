# General

Configure the rule set identity and the destination to use when no computer-name rule matches.

<div class="ui-controls-spacer"></div>

**Rule set name / Description**

Identify the set and its purpose.

**Enabled**

Controls availability for runtime resolution. Disabled sets can still be evaluated in the editor test.

**Domain**

Select an enabled, synchronized AD domain for the destination OUs.

**When no rule matches**

Choose failure, domain default or existing-account location, or a specific fallback OU. New sets default to failure.

**Choose fallback OU**

Select the directory location used by the specific-OU fallback.

**Save Changes**

Saves the General settings.

## Permissions

OU Naming Rule View permits viewing; OU Naming Rule Edit is required to save.
