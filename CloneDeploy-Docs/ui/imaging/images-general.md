# General

Maintain identity and availability.

<div class="ui-controls-spacer"></div>

**Name / Description**

Labels the source image and purpose.

**Image type**

Shows the format chosen at creation.

**Enabled**

Controls availability for use.

**Protected**

Prevents deletion.

**Add tag / remove chip**

Updates labels.

**Save changes**

Commits changes.

## Permissions

Access requires Image View permission.
