# SetupComplete

CMD runs as SYSTEM after Windows setup, before existing SetupComplete commands. Do not restart from it. Windows can skip SetupComplete with an OEM product key.

<div class="ui-controls-spacer"></div>

**SetupComplete commands (CMD)**

Edits post-setup commands.

**Save Profile**

Stores content for subsequent preparations.

## Permissions

Access requires Image Prep Profile View permission.
