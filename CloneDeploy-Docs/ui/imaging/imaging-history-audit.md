# Audit

Review administrative changes to the imaging item. These records do not describe device execution output.

<div class="ui-controls-spacer"></div>

**Search audit**

Filter the loaded audit records.

**Date / User / Event / Item / Details**

Inspect the event time, responsible account, operation and recorded context.

**Paging**

Browse the retained records loaded for this view.

Times are shown in UTC. Search and paging operate on the latest 200 loaded audit records, rather than searching all retained history.
