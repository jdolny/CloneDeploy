# Drivers

Choose Windows driver selection during imaging.

<div class="ui-controls-spacer"></div>

**Driver selection**

Chooses fixed, automatic or no-driver behavior as offered.

**Driver pack**

For fixed selection, uses this pack regardless of hardware matching.

**Automatic matching**

Matches detected hardware against enabled packs. Automated deployment warns and continues if no unique match exists; manual deployment allows selection.

**Save Drivers**

Saves selection for subsequent deployments.

## Permissions

Access requires Deployment Profile View permission.
