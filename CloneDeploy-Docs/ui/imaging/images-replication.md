# Replication

Choose storage destinations for approved image versions. Replication runs in the background; incomplete copies are not offered for deployment.

<div class="ui-controls-spacer"></div>

**Replication destinations**

Select the destinations that should retain copies of approved versions. Selecting an active version does not approve it.

**Save destinations**

Saves the destination selection. The primary copy is retained. Removing a destination removes replicas after active deployments finish.

**Refresh status**

Reloads version and destination status. Interrupted transfers restart from the beginning.

## Permissions

Image View permits viewing; changing destinations requires the applicable image-edit access.
