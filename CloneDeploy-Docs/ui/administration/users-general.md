# General

Update identity and security requirements. Save General commits this tab; entering a new password resets it, while an empty password leaves it unchanged.

<div class="ui-controls-spacer"></div>

**Username**

Name used to identify and sign in as the account.

**Email**

Email address associated with the account.

**Membership**

Administrator grants administrative access; a regular user relies on assigned permissions.

**Password**

Set a replacement password. Do not use this field merely to view an existing password.

**Lockout Enabled**

Allows the sign-in failure policy to lock the account after repeated failures.

**Require Web MFA**

Requires the account to satisfy MFA when using the web interface.

**Require Imaging MFA**

Requires MFA for imaging sign-in.

**User ID / Two-factor authentication enabled / Failed attempts / Lockout ends**

Read-only account state for diagnosing sign-in problems. Requiring MFA and having an authenticator configured are different states.

**Save General**

Saves the account fields and any replacement password.
