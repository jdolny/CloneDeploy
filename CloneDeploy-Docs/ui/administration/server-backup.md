# Backup

Create and review database backups. A database backup does not include deployment content, server configuration, keys or certificates; retain these separately for recovery.

<div class="ui-controls-spacer"></div>

**Back up database**

Starts a background backup. You may leave the page while it runs.

**File / Size / Completed / Server location**

Identify completed backup files and where the server stored them.

## Permissions

Administrator access is required.
