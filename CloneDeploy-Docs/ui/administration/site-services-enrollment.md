# Enrollment

Track enrollment, download replacement setup files before redemption, and compare the installation fingerprint.

<div class="ui-controls-spacer"></div>

**Download new setup file**

For a Created registration, rotates the token and starts a new 24-hour validity window. The previous file becomes invalid.

**Setup expiry**

Deadline for initial token redemption; it is not the lifetime of an approved service.

**Pending request**

Use Configuration to compare its fingerprint and approve it. A consumed token cannot bind another installation.

**Revoke**

Available in the detail header. Confirm to remove service access. Existing connections close after the service receives the revocation; a replacement requires a new registration.

**Back to Site Services**

Returns to the search page. Tab URLs can be bookmarked.

## Permissions

Administrator access is required.
