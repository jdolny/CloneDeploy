# Storage

Manage storage providers attached to this Site Service. This tab is unavailable for Windows Worker services.

<div class="ui-controls-spacer"></div>

**Name / Type / Storage host / Path**

Identify each provider and its storage destination.

**Storage roles**

Identify whether the provider supplies management content, imaging content or both.

**Preferred client networks**

Set the client networks that prefer this storage destination.

**Mount status**

Review the latest reported connection state.

**New storage provider**

Open the provider editor for this site.

**Delete Selected**

Remove selected providers only after resolving references and active-use restrictions.

## Permissions

Administrator access is required.
