# Storage Providers

Open a provider to edit it. Connection status describes the most recent check, not a guarantee of future access.

<div class="ui-controls-spacer"></div>

**New storage provider**

Opens the provider configuration dialog to set its host, purposes, defaults, client networks and local or SMB connection settings. Provider Configuration in the navigation documents the dialog's fields and content-move controls. Select a provider's name to edit the same settings.

**Search / row selection**

Filter providers and select rows for bulk deletion.

**Connect / check providers**

Creates, reads and deletes a small probe file to verify access. Providers are also checked at startup and periodically.

**Make default**

Directs new content to this provider. Existing files remain on their original provider; this does not migrate content.

**Delete / Delete selected**

Requests removal after confirmation. Resolve references or protected-use errors before deleting storage in use.

**Application identity / Mount folder**

Shows which account performs file access and where provider links are exposed. A folder link does not grant share permissions.

## Permissions

Administrator access is required.
