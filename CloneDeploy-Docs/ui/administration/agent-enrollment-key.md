# Enrollment Key

Agents present the shared enrollment key during initial registration, then use their own certificates after enrollment.

<div class="ui-controls-spacer"></div>

**Generate key / Rotate key**

Creates or replaces the shared enrollment key. Update installation configurations for agents that have not enrolled. Enrolled agents keep using their own certificates.

**Enrollment key / Hide key**

Copy the temporarily displayed key for manual configuration, then hide it. Treat it as a secret.

## Permissions

Administrator access is required.
