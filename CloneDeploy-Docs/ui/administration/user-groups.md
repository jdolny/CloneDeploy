# User groups

Group application users to share access grants. These groups do not target devices or synchronize Active Directory group membership.

**Membership**

Choose Admin or User membership. Admin grants full administrator access to members; User uses the group's configured permissions.

Set MFA requirements for members. Admin membership forces web MFA on. Imaging MFA is independent.

**Create / Cancel**
