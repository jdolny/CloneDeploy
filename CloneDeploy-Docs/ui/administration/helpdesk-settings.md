# Help Desk settings

Administrators can configure categories, queues, and routing rules. Changes to routing rules apply when new tickets are created.

<div class="ui-controls-spacer"></div>

**Categories**

Define the categories used to classify Help Desk tickets.

**Queues**

Organize Help Desk work into queues.

**Routing Rules**

Route newly created tickets through categorization, then queue assignment.

**Scope**

Open **Scope** to configure which devices and users are eligible for Help Desk.

## Permissions

Administrator access is required.
