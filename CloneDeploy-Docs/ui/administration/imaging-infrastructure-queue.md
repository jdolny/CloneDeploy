# Imaging Queue

Control deployment admission across devices. Upload/capture sessions do not count toward this deployment limit.

<div class="ui-controls-spacer"></div>

**Maximum concurrent deployments**

Limits active WIM/FFU deployments. Zero pauses new admission. Lowering the limit lets running deployments finish; waiting devices see their position in WinPE.

**Save / Refresh**

Save the admission limit or reload it.

## Permissions

Administrator access is required.
