# Server administration

Use the server administration tabs for application endpoints, storage, certificates and credentials.

<div class="ui-controls-spacer"></div>

**General**

Set the addresses published to devices.

**Backup**

Create and review database backups.

**Certificates**

Manage the CloneDeploy CA and the main app's service HTTPS certificate.

**Directory Connections**

Import directory objects from Active Directory over LDAPS or Microsoft Entra ID through read-only Graph requests.

**Email**

.

**Managed Credentials**

Store reusable credentials for authorized operations such as domain join, Run As, directory synchronization and SMB access.

**Microsoft Entra**

CloneDeploy supports one LDAP connection and one Entra connection.

**Storage Providers**

Providers hold managed content.

**Task Scheduler**

Control recurring server maintenance and import jobs.

**Professional Support**

View the installation ID, server version, support coverage, and last verification time.

**WinGet**

Import package metadata used by WinGet action selection.

## Permissions

Administrator access is required.
