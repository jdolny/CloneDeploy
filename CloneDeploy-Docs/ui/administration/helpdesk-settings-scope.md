# Scope

Open **Scope** to configure which devices and users are eligible for Help Desk. Save each tab separately.

<div class="ui-controls-spacer"></div>

**Device groups**

Choose all eligible devices or restrict the device scope to selected device groups. When restricting the scope, select the groups to include and save.

**User audiences**

Choose all eligible users or restrict the user scope to selected user audiences. When restricting the scope, select the audiences to include and save. Manage audience membership in User Audiences.

## Permissions

Administrator access is required.
