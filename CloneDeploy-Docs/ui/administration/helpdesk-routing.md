# Routing Rules

Route newly created tickets through categorization, then queue assignment. Each stage uses its first enabled matching rule in ascending order and then rule ID. Changing rules does not reroute existing tickets.

<div class="ui-controls-spacer"></div>

**Categorization**

Maintain conditions that select a category.

**Queue Assignment**

Maintain conditions that select a queue. These conditions can use the category assigned in the preceding stage.

## Permissions

Administrator access is required.
