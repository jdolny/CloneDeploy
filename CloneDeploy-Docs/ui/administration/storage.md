# Storage Providers

Manage content-storage destinations and monitor replication. A connection check reports the latest observed access; it does not guarantee future availability.

<div class="ui-controls-spacer"></div>

**Storage Providers**

Create and maintain providers, inspect mount status and select the default write destination. Provider edits configure paths, access and storage roles.

**Replication Settings**

Set overall bandwidth and concurrent site and shared-file transfer limits.

**Replication Status**

Inspect active and waiting transfers, reported failures and retry times.

## Permissions

Administrator access is required.
