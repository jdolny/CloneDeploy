# Live Activity

Open **Live Activity** under **TFTP & Boot Files** to inspect boot service events. Administrator access is required. The view updates every second and retains the latest 500 events with UTC timestamps.

<div class="ui-controls-spacer"></div>

**Pause / Resume**

Pauses or resumes updates to the view.

**Clear**

Clears this view only.

**Auto-scroll**

Follows new events automatically.

TFTP also shows transfers with client, filename, transferred and total bytes, and status. Pausing or clearing the display does not stop a boot service or transfer.

## Permissions

Administrator access is required.
