# Drivers

Select prepared x64 WinPE packs, generally networking/storage. This is separate from deployed Windows drivers.

<div class="ui-controls-spacer"></div>

**Driver packs**

Copies chosen package revisions into the next build.

**Ready counts**

Shows preparation status; resolve unavailable content before building.

**Manage driver packs**

Opens content preparation.

**Save changes**

Stores the selection.

## Permissions

Administrator access is required.
