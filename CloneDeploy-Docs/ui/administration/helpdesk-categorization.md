# Categorization

Define rules that assign a category when a ticket is created. The first enabled matching rule wins.

<div class="ui-controls-spacer"></div>

**Add rule**

Opens the rule editor.

**Name / Order / Enabled**

Identify the rule, set its evaluation order and enable it.

**Conditions**

Choose whether all or any conditions must match. Conditions can use ticket text, device information and synchronized directory membership or OU ancestry. A rule without conditions is a catch-all; place it after more specific rules.

**Category**

Choose the category to assign.

**Save rule**

Saves the rule for new tickets. Deleting it leaves existing ticket routing unchanged.

## Permissions

Administrator access is required.
