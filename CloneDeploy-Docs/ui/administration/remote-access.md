# Remote access

Control whether remote viewing requires user approval, using a global default and exceptions for particular devices or groups. Changes apply to new sessions; the viewing and control permissions are enforced separately from these consent settings.

<div class="ui-controls-spacer"></div>

**Global configuration**

Set the consent mode used when no enabled rule matches a device.

**Rules**

Create and maintain prioritized exceptions for selected devices or device groups. The enabled matching rule with the lowest priority number wins.

## Permissions

Administrator access is required to configure remote access. Operators still need Device Remote View and, for input, Device Remote Control permissions.
