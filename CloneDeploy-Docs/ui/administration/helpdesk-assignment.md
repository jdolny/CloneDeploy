# Queue Assignment

Define rules that assign a queue when a ticket is created. The first enabled matching rule wins.

<div class="ui-controls-spacer"></div>

**Add rule**

Opens the rule editor.

**Name / Order / Enabled**

Identify the rule, set its evaluation order and enable it.

**Conditions**

Choose whether all or any conditions must match. Conditions can use ticket text, device information and synchronized directory membership or OU ancestry. If no rule matches, the ticket enters Unassigned.

**Queue**

Choose the queue to assign.

**Save rule**

Saves the rule for new tickets. Deleting it leaves existing ticket routing unchanged.

## Permissions

Administrator access is required.
