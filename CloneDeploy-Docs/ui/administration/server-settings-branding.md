# Branding

Open **Agent Settings → Branding** to customize organization branding for the agent portal and message actions that select organization branding. Devices receive changes at their next check-in.

<div class="ui-controls-spacer"></div>

**Organization name / Tagline**

Optional organization text displayed in branded experiences.

**Header/sidebar color**

Hex color such as `#651C32`; text contrast adjusts automatically.

**Accent color**

Color used for buttons, links, selection and keyboard focus.

**Logo upload**

Use a PNG up to 64 KiB and 512 by 512 pixels. Transparent backgrounds work well.

**Remove logo**

Clears the custom image from the pending branding settings.

**Reset to CloneDeploy defaults**

Restores the default appearance choices; save to apply them.

**Preview**

Shows pending branding, not a live message. Message timeout, acknowledgment and placement belong to the message action.

**Reload / Save**

Reload saved branding or persist the edited branding.

## Permissions

Administrator access is required.
