# Replication Status

Inspect current and waiting replication work. The view refreshes every five seconds; worker reports can lag current activity.

<div class="ui-controls-spacer"></div>

**Destination / Host**

The storage destination and host handling the transfer.

**State / Last update**

The latest reported state and its time. Check the displayed last-check time before interpreting activity.

**Error / Retry time**

Reported failure details and the next retry time, when available.

## Permissions

Administrator access is required.
