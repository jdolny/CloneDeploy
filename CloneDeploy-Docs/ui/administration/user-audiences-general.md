# General

Identify this reusable policy audience. Changes affect later policy admission; already admitted runs continue.

<div class="ui-controls-spacer"></div>

**Name**

Enter a unique audience name.

**Description**

Add optional administrative notes.

**Save Changes**

Saves the audience. An empty draft grants no access. A policy must release its assignment before the audience can be deleted.

## Permissions

User Audience View permits viewing; User Audience Edit is required to save changes.
