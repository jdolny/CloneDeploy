# Resolved users

Inspect the users resolved from the audience's saved membership selections. Save membership changes before checking the results.

<div class="ui-controls-spacer"></div>

**Name / Username / Directory**

Review the resulting eligible directory users. Exclusions take precedence over inclusions.

**Search**

Find resolved users by name, username or directory.

**Refresh**

Resolve the saved selections again. Directory membership still reflects the last successful synchronization.

**Paging / Last sync**

Browse resolved users and check each contributing directory's sync time and availability.

## Permissions

User Audience View is required.
