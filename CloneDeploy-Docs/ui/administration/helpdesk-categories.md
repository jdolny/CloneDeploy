# Categories

Define the categories used to classify Help Desk tickets. Categories referenced by tickets or routing rules cannot be deleted.

<div class="ui-controls-spacer"></div>

**Add category / Edit**

Open the category editor.

**Name**

Enter the category name shown to staff.

**Save changes**

Saves the name. Staff assignments and automatic categorization determine which tickets use it.

**Delete**

Removes an unused category after the applicable confirmation.


**Create / Cancel (category dialog)**

Name is required and limited to 100 characters. Create saves a new category; Save changes renames an existing one. Cancel discards the name edit.

## Permissions

Administrator access is required.
