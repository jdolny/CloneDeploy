# Replication Settings

Control replication concurrency and bandwidth across storage destinations. Site-specific limits may further constrain transfers.

<div class="ui-controls-spacer"></div>

**Concurrent sites**

Number of sites processed concurrently, from 1 to 32.

**Concurrent shared / management files**

Concurrent shared-management file transfers, from 1 to 16.

**Overall replication bandwidth (MiB/s)**

Overall bandwidth limit in MiB/s. Zero means unlimited; a site-specific limit can impose an additional cap.

**Save replication limits**

Saves the limits for replication work.

## Permissions

Administrator access is required.
