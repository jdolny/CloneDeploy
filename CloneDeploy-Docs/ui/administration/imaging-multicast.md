# Multicast

Set the sender address used by new multicast sessions hosted on the Main App. Existing sessions keep their original sender address.

<div class="ui-controls-spacer"></div>

**Multicast sender IPv4 override**

Leave blank to use Main Server IP, or enter another IPv4 address assigned to the server on the imaging network. An IPv4 override is required if Main Server IP is IPv6.

**Save Changes**

Saves the override for future sessions. Clearing it restores the default address.

## Permissions

Administrator access is required.
