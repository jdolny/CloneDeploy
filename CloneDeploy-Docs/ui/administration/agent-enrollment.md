# Agent administration

Configure enrollment rules, normal agent check-ins and downloadable agent releases. Agent approval requests are handled under Devices > Approval / Reset Requests.

<div class="ui-controls-spacer"></div>

**General**

These limits control shared server capacity and apply across server instances.

**Agent tools**

Restrict the networks allowed to use direct agent-tools sign-in.

**Branding**

Open **Agent Settings → Branding** to customize organization branding for the agent portal and message actions that select organization branding.

**Enrollment**

Control how agents join the installation.

**Features**

Open **Agent Settings → Features** to enable Help desk, Self service and WinGet integration globally.

**Installer & Updates**

Prepare a deployment ZIP for this server.

**Remote access**

Control whether remote viewing requires user approval, using a global default and exceptions for particular devices or groups.

## Permissions

Administrator access is required.
