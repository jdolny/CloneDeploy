# Imaging infrastructure

Configure local PXE boot services and imaging capacity. ProxyDHCP and TFTP operate on the networks that can reach these listeners; they are separate from the HTTPS SiteService reverse proxy.

<div class="ui-controls-spacer"></div>

**Deployment Performance**

These settings apply to new deployment sessions.

**Imaging Queue**

Control deployment admission across devices.

**Multicast**

Set the sender address used by new multicast sessions hosted on the Main App.

**PXE Proxy**

Manage PXE Proxy configuration and inspect service activity.

**TFTP & Boot Files**

Manage TFTP & Boot Files configuration and inspect service activity.

**WinPE Boot Environments**

Boot environments define the WinPE settings used to start devices for imaging.

**WinPE Builder**

Prepare the Windows builder and review its setup jobs.

## Permissions

Administrator access is required.
