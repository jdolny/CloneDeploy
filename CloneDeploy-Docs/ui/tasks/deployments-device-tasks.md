# Action deployments — Device tasks

Loss of reporting can leave execution unknown; it does not prove that the process stopped.

<div class="ui-controls-spacer"></div>

**Refresh tasks**

Retrieves current task states.

**Cancel unstarted tasks / Cancel task**

Prevents unstarted work; does not interrupt running tasks.

**Confirm stopped**

Releases unknown-task capacity only after you verify execution has stopped. Otherwise capacity remains reserved until the agent reports.

**Result**

Displays reported output and outcome in the device-task table.

**Search devices / filters / paging**

Narrows the device tasks.

**All deployments**

Returns to the deployment list.
