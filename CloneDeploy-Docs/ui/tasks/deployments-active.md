# Active

Shows the latest 200 active deployments. Direct actions are delivered to connected agents immediately or at their next check-in, according to the selected delivery timing.

<div class="ui-controls-spacer"></div>

**Refresh deployments**

Reloads counts and states.

**Search deployments / filters / paging**

Narrows the displayed subset by action, requester, source or delivery.

**Action name**

Opens device tasks and their results, cancellation and unknown-outcome review.

**Show all deployments**

Clears the unknown-outcome filter when it is active.
