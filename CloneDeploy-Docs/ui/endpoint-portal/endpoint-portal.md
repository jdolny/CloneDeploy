# Endpoint Portal

The Endpoint Portal gives users access to services on their managed computer. It communicates with the local CloneDeploy agent and provides device status, notifications, self-service policies and Help Desk requests.

The available sections and actions depend on the operating system, enabled agent features, connection state and user access. Administrators configure these features in the Web UI. Branding can also change the portal's title and appearance.

Self-service policies must be active and available to the signed-in user before they appear. Help Desk access depends on the configured user and device scope. A connection or account problem can prevent these features from loading even when the portal itself opens.
