# Client results

Review the latest 200 device-reported policy results, with date, device and user. A pending or missing result does not prove success.

<div class="ui-controls-spacer"></div>

**Client results**

Selects this view on Activity. Switching views does not change or run the policy.

**Search**

Search client results matches device, user and result.

**Refresh history**

Reloads recorded entries.

**Paging**

Browses the displayed subset.
