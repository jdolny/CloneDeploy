# Published versions

Review the latest 200 published versions. Each hash identifies saved policy content; the current editor may have changed since a version was published.

<div class="ui-controls-spacer"></div>

**Published versions**

Selects this view on Activity. Switching views does not change or run the policy.

**Search**

Search published versions matches the hash.

**Refresh history**

Reloads recorded entries.

**Paging**

Browses the displayed subset.

**View policy**

Expands the stored JSON for that version.
