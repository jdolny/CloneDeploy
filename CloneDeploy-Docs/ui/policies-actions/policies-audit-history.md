# Audit history

Review the latest 200 recorded administrative policy events. This records administrator operations rather than agent execution results.

<div class="ui-controls-spacer"></div>

**Audit history**

Selects this view on Activity. Switching views does not change or run the policy.

**Search**

Search audit history matches user and operation.

**Refresh history**

Reloads recorded entries.

**Paging**

Browses the displayed subset.
