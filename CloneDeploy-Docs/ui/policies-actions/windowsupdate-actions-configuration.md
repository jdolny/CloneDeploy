# Configuration

Use the device’s configured Windows Update source. This action does not change its source or WSUS configuration.

<div class="ui-controls-spacer"></div>

**Operation**

Select the available scan/install mode. Approved installation is limited to revisions approved in Windows Update reporting; an empty approval set installs nothing.

**Timeout (minutes)**

Maximum time allowed for the update action.

**Save changes**

Saves update behavior. Available, non-hidden updates are considered. Restart requirements are reported, not silently resolved; configure policy completion or restart separately.

## Permissions

Access requires Policy View permission.
