# Configuration

Copy attached content to a device. Attach the files on Files and configure their destination here.

<div class="ui-controls-spacer"></div>

**Destination path**

Target location on the managed device, not a server storage-provider path.

**Decompress after copying**

Extracts supported archive content after transfer instead of leaving only the copied archive.

**Overwrite existing files**

Allows replacement of existing destination files. Confirm that the target path is correct before deployment.

**Save changes**

Saves transfer behavior. It does not send files immediately; use Deploy or an active policy.

## Permissions

Access requires Policy View permission.
