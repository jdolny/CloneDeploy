# Script actions

Store a script used for execution, a condition, or custom inventory. A script has one purpose; selecting both condition and inventory is not supported.

Search the action catalog, open an action name to edit it, or use New to enter a name and description. Creating an action does not run it.

<div class="ui-controls-spacer"></div>

**Search actions / Tags / Match**

Filters the catalog; Match selects all-versus-any tag behavior.

**Include archived**

Includes actions no longer available for ordinary use.

**Archive / Restore**

Retains the action while taking it out of active use, or returns it to availability.

**Delete / Delete selected**

Requests removal after confirmation. References can prevent deletion; inspect Relations first.

**Deploy**

Runs the saved action once on selected devices through the deployment wizard. Save edits first.


**Name / Description (creation dialog)**

Enter a required name and an optional description for the new action. These identify the shared action; configure its operation after creation.

**Create / Cancel**

Create saves the action and opens it for configuration. It does not deploy the action. Cancel closes the dialog without creating it. Creating requires Policy Edit permission.

## Permissions

Access requires Policy View permission.
