# History

Inspect client results, published versions and administrative audit history.

<div class="ui-controls-spacer"></div>

**Client results**

Device-reported executions and their outcomes; refresh to retrieve later results.

**Published versions**

Latest 200 policy snapshots. Use these to inspect exactly what was published, especially after a shared action changes.

**Audit history**

Recorded administrative changes.

**View policy**

Expands the stored JSON for a published version.

**Search / Refresh history**

Filters the chosen displayed history or reloads its entries.

Read the separate Client results, Published versions and Audit history references.

## Permissions

Access requires Policy View permission.
