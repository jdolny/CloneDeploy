# Relations

Inspect saved relationships for this item. This view does not change assignments or confirm that work executed.

<div class="ui-controls-spacer"></div>

**Type / All**

Select a relationship category or show all categories.

**Search relations**

Filter by the displayed relationship information.

**Related item / Connection**

Identify an associated record and its connection. Select an available item link to open it.

**Included by**

Shows the source that introduces a related item, when available.

**Refresh**

Reloads relationships.

**Paging**

Browse matching records.

## Permissions

Access requires Policy View permission.
